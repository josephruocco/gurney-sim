GURNEY SIMULATOR — WINDOWS ONLINE TEST

Windows x64 development package. Godot is included; no separate install needed.

1. Right-click the ZIP and choose Extract All. Keep the extracted folder together.
2. Double-click Start.bat. The first launch prepares the game files.
   This is an unsigned test package; Windows may show a security prompt.
   Only run it if you trust the person who sent it. Do not disable antivirus.
3. Enter your name in the Shift Lobby.
4. Under PLAY ONLINE — ROOM CODE, leave the prefilled server address unchanged.
5. One person clicks Create room and shares the code. The other enters that
   code and clicks Join room. Mac and Windows players can share a room.
6. Both click Ready up after both names appear.

Use Create room / Join room, not Host / Join localhost, for internet play.
Both players need internet but can use different Wi-Fi networks.
WASD moves; E grabs/releases the gurney; Space brakes; host presses R to retry.
Closing the host ends the room. Restart the game before changing roles.

This package's files were checked on a Mac. Actual Windows launch and
Mac-to-Windows gameplay still need testing.
