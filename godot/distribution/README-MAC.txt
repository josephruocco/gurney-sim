GURNEY SIMULATOR — TWO MAC ONLINE TEST

Development test package; not a signed App Store release.
Includes a universal Godot runtime for Intel and Apple Silicon Macs.

1. Send the ZIP to your friend and unzip it on both Macs.
2. Open Start.command inside Gurney-Simulator. Keep the folder together.
   If macOS blocks it, review the block in System Settings > Privacy & Security
   and allow the package only if you trust its source.
3. Enter your name. Under PLAY ONLINE — ROOM CODE, the relay is prefilled:
   wss://gurney-relay.onrender.com
4. One player clicks Create room and shares the displayed room code.
5. The other enters that code and clicks Join room.
6. Confirm both players appear in the roster. Both click Ready up.
7. WASD moves. E grabs/releases the gurney. Space brakes.
   The host presses R after a loss to retry.

Use Create room / Join room for this online test, not Host / Join localhost.
Both Macs need internet; they can be on the same or different Wi-Fi networks.
No router port forwarding is needed for the room-code connection.
Keep the host's game open. Closing it ends the room.
Close and reopen the game before changing roles or starting a fresh session.

Check that both avatars appear and movements show on the other computer;
check grabbing, gurney/patient motion, and matching end results.
Two game processes have connected through the public relay and synchronized
world state. Two separate physical computers still need testing.
